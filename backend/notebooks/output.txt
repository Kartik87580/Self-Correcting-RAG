# 🟢 Simple RAG Code (LangChain + Qdrant + Recursive Chunking) 🚀

---

## ⚙️ What this code does

* Takes **text string as input**
* Splits using **Recursive Chunking**
* Creates **embeddings**
* Stores in **Qdrant (local)**
* Retrieves relevant chunks
* Sends to LLM → generates answer

## 🧠 Complete Easy Code

```python
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain.embeddings import OpenAIEmbeddings
from langchain.vectorstores import Qdrant
from langchain.chat_models import ChatOpenAI
from langchain.chains import RetrievalQA
from qdrant_client import QdrantClient

# -------------------------------
# 1. Your Text Data (INPUT)
# -------------------------------
text_data = """
Artificial Intelligence is transforming industries. 
Machine learning is a subset of AI. Deep learning uses neural networks.
RAG helps reduce hallucination in LLMs by retrieving relevant information.
"""

# -------------------------------
# 2. Chunking (Recursive)
# -------------------------------
splitter = RecursiveCharacterTextSplitter(
    chunk_size=100,
    chunk_overlap=20
)

docs = splitter.create_documents([text_data])

# -------------------------------
# 3. Embeddings
# -------------------------------
embeddings = OpenAIEmbeddings()  # requires OPENAI_API_KEY

# -------------------------------
# 4. Qdrant (Local Setup)
# -------------------------------
client = QdrantClient(":memory:")  # local in-memory DB

vectorstore = Qdrant.from_documents(
    docs,
    embeddings,
    location=":memory:",
    collection_name="my_collection"
)

# -------------------------------
# 5. Retriever
# -------------------------------
retriever = vectorstore.as_retriever(search_kwargs={"k": 2})

# Test retrieval
query = "What is RAG?"

retrieved_docs = retriever.get_relevant_documents(query)

print("\n🔍 Retrieved Chunks:\n")
for i, doc in enumerate(retrieved_docs):
    print(f"Chunk {i+1}: {doc.page_content}\n")

# -------------------------------
# 6. LLM + RAG
# -------------------------------
llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)

qa_chain = RetrievalQA.from_chain_type(
    llm=llm,
    retriever=retriever
)

# Final Answer
response = qa_chain.run(query)

print("\n🧠 Final Answer:\n")
print(response)
```

---

## 🔍 Code Flow (Simple)

```
Text → Chunking → Embeddings → Qdrant
                         ↓
Query → Retrieve Top Chunks → LLM → Answer
```

---

## ⚡ Key Points (Interview)

* **Recursive Chunking** = best general chunking
* **Qdrant local (:memory:)** = no setup needed
* **Retriever k=2** = fetch top 2 relevant chunks
* LLM gets **context + query** → better answer
